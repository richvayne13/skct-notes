# 🚀 SKCT 마스터 오답노트 (SKCT Master Error Notes)

> **스마트 화면 캡처 `Ctrl+V` 클립보드 등록, 수리·추리 심층 세부분류, 풀이/정답 사전 블러(Blur) 가림, 줄글 전략 메모장, Git & GitHub Pages 온라인 연동 지원**

---

## 📌 주요 핵심 기능

### 1. 📷 초고속 화면 캡처 `Ctrl + V` 등록 시스템
- 드래그 앤 드롭의 번거로움 없이, `Win + Shift + S` 등으로 캡처 후 **클릭하고 `Ctrl + V`만 누르면 즉시 삽입**됩니다.
- **스마트 3단계 순차 자동 이동 (Quick Wizard)**:
  - 1회 붙여넣기 $\to$ [문제] 등록 후 자동으로 [풀이]로 이동
  - 2회 붙여넣기 $\to$ [풀이] 등록 후 자동으로 [정답]으로 이동
  - 3회 붙여넣기 $\to$ [정답] 등록 완료! 10초 만에 오답노트 작성 끝!
- 버튼 하나로 클립보드 이미지를 가져오는 `클립보드에서 가져오기` 원클릭 버튼 제공.

### 2. 🎯 SKCT 최신 5대 영역 및 수리·추리 심층 세부분류
- **언어이해**: 지문 독해, 글의 전개 방식, 사실 일치, 빈칸 어휘
- **자료해석 (수리)**: 증가율/변화율 비교, 비중/구성비, 배율·지수 분석, 분수 대소 비교 및 가평균, 복합 차트 빈칸
- **창의수리 (수리)**: 거속시(거리·속력·시간), 소금물/농도, 일률, 원가·정가·할인율, 경우의 수 및 확률, 정수론(약수·배수·나머지)
- **언어추리 (추리)**: 명제추리(삼단논법, 대우), 조건추리(속성 매칭, 순서 나열, 자리배치), 참/거짓 진실게임, 논리적 오류
- **수열추리 (추리)**: 등차/등비수열, 계차수열, 군수열, 피보나치/누적수열, 건너뛰기/교대수열, 분수/특수수열
- *(보너스)* **실행역량**: 비즈니스 업무 우선순위 및 상황 판단

### 3. 🔒 실전 대비 풀이·정답 사전 블러(Blur) 가림 & 1분 스톱워치
- 오답 카드에서는 **문제만 선명하게 표시**되며, 풀이과정과 답은 강력한 가우시안 블러(`filter: blur(14px)`)와 가림막으로 숨겨집니다.
- `👁️ 정답 & 풀이과정 확인` 버튼을 누를 때만 부드럽게 해제되어 실전처럼 먼저 혼자 풀어볼 수 있습니다.
- 상단 툴바의 `🔒 전체 풀이/답 숨김/공개` 마스터 버튼으로 한 번에 토글 가능.
- **⏱️ 실전 1분 집중 풀이 모드**: 큰 화면 모달과 함께 60초 카운트다운 타이머가 작동하여 실전 시간 감각을 훈련할 수 있습니다.

### 4. 📝 줄글 오답 비법 & 공식 전략 메모장
- 문제 캡처 이미지 외에도 **자주 잊어버리는 공식, 자주 범하는 계산 실수, 시험 직전 10분 요약 팁**을 텍스트 및 마크다운 형태로 체계적으로 정리할 수 있습니다.

### 5. 🎨 비비드(Vivid) & 글래스모피즘 디자인
- SK의 역동적인 일렉트릭 오렌지, 네온 핑크, 사이버 인디고, 에메랄드 그린 컬러 팔레트.
- 헤더를 좌측으로 배치한 **모던 좌측 사이드바 레이아웃**.
- 다크 모드 및 라이트 모드 완벽 지원.

### 6. 💾 대용량 IndexedDB 로컬 영구 저장 & JSON 백업/복원
- 브라우저 IndexedDB를 활용하여 용량 제한 없이 수백 장의 고화질 캡처 이미지를 안전하게 영구 저장합니다.
- `💾 백업` 버튼으로 전체 오답 데이터를 단일 JSON 파일로 추출하고, `📂 복원` 버튼으로 언제든 복구할 수 있습니다.

## 🌐 Git 연동 및 GitHub Pages 무료 온라인 배포 방법

본 프로젝트는 외부 백엔드 서버나 복잡한 빌드 과정 없이, GitHub Pages에서 100% 무료로 동작하는 초경량 순수 웹앱(SPA)입니다.

### 방법 1. 제공된 `deploy.bat` 원클릭 실행 (Windows)
1. GitHub(github.com)에 로그인 후 새 Repository를 생성합니다 (예: `skct-notes`).
2. `tool/skct-note/deploy.bat`을 실행합니다.
3. 안내에 따라 본인의 GitHub 리포지토리 URL을 붙여넣으면 자동으로 원격 push가 완료됩니다!

### 방법 2. 수동 커맨드라인 연동
`tool/skct-note` 폴더에서 터미널(PowerShell 등)을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# 1. 로컬 저장소 상태 확인 및 커밋
git add .
git commit -m "SKCT 오답노트 초기 구성"

# 2. 본인의 GitHub 리포지토리 주소 연결 (URL 교체 필요)
git remote add origin https://github.com/<당신의GitHub아이디>/<저장소이름>.git

# 3. main 브랜치 푸시
git branch -M main
git push -u origin main
```

### GitHub Pages 온라인 사이트 활성화
1. 본인의 GitHub 저장소 페이지에서 **[Settings]** 탭 클릭
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Build and deployment > Source**에서 **Deploy from a branch** 선택
4. Branch를 `main` / `root` 로 설정하고 **Save** 클릭
5. 약 1분 후 `https://<당신의GitHub아이디>.github.io/<저장소이름>/` 주소로 전 세계 어디서든 접속 가능한 나만의 온라인 SKCT 오답노트 사이트가 열립니다!
