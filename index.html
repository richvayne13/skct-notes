READY TO DEPLOY

로컬 Git 저장소 및 배포 스크립트 구성 완료!

이 웹 애플리케이션은 서버 없이 GitHub Pages에서 100% 무료로 동작하는 초경량 정적 웹앱입니다.

1
GitHub에 새 Repository 생성

GitHub(github.com)에서 skct-notes 이름으로 새 빈 리포지토리를 생성합니다.

2
원격 저장소 연결 및 원클릭 푸시

작업 폴더의 tool/skct-note 경로에서 터미널을 열고 아래 명령어를 입력하거나 함께 제공된 deploy.bat을 실행하세요:

git remote add origin https://github.com/당신의아이디/skct-notes.git
git branch -M main
git push -u origin main
3
GitHub Pages 활성화

저장소 [Settings] > [Pages] 메뉴에서 Source를 Deploy from a branch (main / root)로 설정하면 수초 내에 온라인 링크가 생성됩니다!

💡 데이터 백업 팁: 캡처한 오답 데이터는 좌측 사이드바의 [💾 백업] 버튼으로 JSON 파일로 저장한 후 Git 저장소에 커밋하여 영구 보관할 수 있습니다.
